## 如何打开体验

1. **优先**：解压后用浏览器直接打开本目录中的 `index.html`（不必安装依赖，也没有构建步骤）。路径全部为相对路径，脱机可打开，不依赖必须联网的字体或脚本 CDN。
2. **备选**：若某款浏览器对 `file://` 本地文件限制较严（例如部分拦截本地存储），可在本目录打开终端并运行：

```bash
python3 -m http.server
```

然后在浏览器访问终端里提示的本地地址（通常是 `http://127.0.0.1:8000/`）。这只是本机预览，不是公网部署。

审核人不必阅读代码。打开后请先看应用内的 **「体验说明」** 页（顶部工具条即可进入），其中有页面导航和六条核心流程的逐步点击路径。

## 本样品包含什么

- 顾客端：浏览门店与项目、指定技师、选择可用时段并提交预约（先预约后结算，无需先付款）、查看我的预约与次卡余次。
- 店员端：今日看板、服务状态推进（已确认 → 已到店 → 服务中 → 待结算 → 已完成）、待结算核销、顾客查询、房态板、排班只读。店员不能把自己提成馆主，也不能做老板才有的配置与发卡。
- 老板端：动态经营看板、预约管理、项目 / 员工 / 排班 / 房间 / 次卡发放 / 统计、确认方式（需要确认 / 自动确认）与清扫缓冲等设置、身份权限。
- 规则：技师锁与房间锁相互独立；同一技师或同一房间在同一连续时段不能重复占用；服务结束后房间进入可配置清扫缓冲（默认 15 分钟）；确认超时释放占用；次卡按次核销，不能扣成负数或重复核销。

尚未实现（不要当作可用）：加钟、轮牌、一房多床位、美团 / 抖音等平台对接、硬件收银或房间设备、真实支付、提成分账、连锁总部。

## 可选自测

审核人不必运行测试。开发自测：

